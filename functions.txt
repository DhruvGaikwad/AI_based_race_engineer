PYACCSHAREDMEMORY REFERENCE

MAIN CLASS
accSharedMemory()

MAIN METHODS
accSharedMemory()
- Opens the ACC shared memory blocks

read_shared_memory()
- Reads ACC shared memory
- Returns an ACC_map object
- Returns None if the library thinks physics has not changed

get_shared_memory_data()
- Keeps trying until data is available
- Returns ACC_map
- Raises timeout if nothing is read

close()
- Closes the shared memory connection


TOP LEVEL RETURN OBJECT
ACC_map

ACC_map contains:
- Physics
- Graphics
- Static
